Each entry documents a real loss event: the vulnerable contract's flaw, the attacker's flow with the actual numbers, and the transferable lesson for auditors and bug hunters.

How to use it

  • By class — open Intelligence and read the incident cluster for a root-cause class; the pattern emerges fast.
  • By time — the database is time-ordered: access-control and reentrancy dominated 2021-22, oracle and flash-loan attacks peaked in 2022-23, and recent years shifted to novel protocol-logic flaws.
  • Before an audit — pick the protocol category in Checklists and use the lessons as your first audit checklist.

Methodology

Every finding follows the discipline described in Methodology: hand-derived economics, live-reachability proof, prior-art honesty and honest severity.
